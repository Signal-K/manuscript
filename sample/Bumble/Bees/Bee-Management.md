# Bee Management System

## Hive Population System

### Current Basic System
- 25 option spawn: bee every 2 hours
- Need more sophisticated population management

### Proposed Hive Mechanics

**Hive Capacity:**
- **First ratio:** Hive can hold full population of 3-10 bees
- **Second ratio:** Hive increases by one bee per day or being
- **Countdown:** Hive brings to 5x capacity = 20 maximum

### Population Growth
- Hive capacity determines maximum bee population
- Growth rate based on hive level and conditions
- **More hives = faster bee growth**

## Honey Production Pipeline

### Collection System
- Bees collect pollen and eat nectar from plants
- Each bee can carry one serving of each resource
- Regular tabular collection pattern

### Storage & Processing
- Bees deposit nectar into hive slots
- Groups nectar into honey production
- **Hives have 20 slots total**
- **All nectar becomes honey by default**
- **2 honey slots consumed by one bee**

### Resource Flow
**Collection → Transport → Storage → Processing → Consumption**

## Classification Integration

### World Bee Discovery
Finding bees in the world (classification crank) results in:
- **New bee added to your hive**
- **Bonus effect on yield**

This creates gameplay loop connecting citizen science to game progression.

## Table Management System

### Plot Type Management
- Misc. soil plot types
- Leave some plots to decay (strategic choice)
- Numbers tracked per plot
- **Bees are assigned by type**
- Each plot has soldier/worker bee assignments

### Bee Specialization
Different bee types for different functions:
- Collection specialists
- Production specialists  
- Guard/soldier bees
