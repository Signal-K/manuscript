# UI & Visual Design

## Design Philosophy

**First priority:** Design clean and minimal UI for classification that matches agricultural texture/style

### Current Issues
- Classification UI looks out of place compared to rest of Bumble
- Text/background pages need overhaul - they look bad
- Need to match agricultural aesthetic throughout

## Art Assets

### Tilesheets
- Created new tilesheets in Pixilart.com (Nov 19)
- Next: identical layout scenes with different colors for grass/ground/water (different planets/biomes)
- Use default lighting methods rather than manual texture color changes for time/sunlight

### Sprites Needed
- Player character
- Trees
- Flowers (for fishing mechanic)

## Crafting Interface

**Decision:** Crafting grid/UI should be simple like old MCPE crafting UI
- Keep it minimal and intuitive
- Match agricultural aesthetic
- Easy to understand at a glance
