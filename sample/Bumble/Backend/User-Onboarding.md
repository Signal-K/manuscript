# User Onboarding

## Guest Account System

### Auto-Creation
**Decision:** Create guest account automatically when installing app

**Benefits:**
- Removes friction from first-time experience
- Users can start playing immediately
- Lower barrier to entry

### Account Merging
- Option to connect/merge guest account with existing account later
- Preserves progress when user decides to create full account

### Cleanup
- Script needed to remove guest accounts locally that are >1 day old
- Prevents accumulation of unused accounts

## Distribution Strategy

### Initial Distribution (Nov 9)
Distributing Bumble APK file

**Key Questions for Distribution:**
1. Does game loop make sense?
2. Does classification UI fit in?
3. Does it look good?
4. Does it run on Android?

### Rollout Plan (Proposed)
1. Wrap up Bumble and distribute
2. Web app version
3. PWA (Progressive Web App)
4. Native app (iOS and Android)
