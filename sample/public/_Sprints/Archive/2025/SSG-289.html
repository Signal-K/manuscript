Fast-Deploy

The basics -

  1. If a user has never deployed a tool before (determined by the classifications they’ve made), we will have a quick deploy mechanic, which reduces all time taken for anomalies to become available to either 0 seconds, or 1 minute (between each waypoint, for the AI4M Rover project)
  2. The sector or waypoint is automatically selected
  3. The user is given more information text on the viewport window

To make things even easier for new users, we’ll update the main homepage with a simple button to activate (fast deploy) all of their tools, and then we’ll give them a one-question quiz-type experience which will send them to the viewport that is most relevant to what they want to do; the linked_anomalies entries will have already been created and this allows the user to jump right into the action.

This does lead into a post-sprint question/discussion topic: what will we have users do after this classification/onboarding experience?

We’ll also give users an option to have the fast deploy (i.e. automatic selection) enabled for the future; but the time delay for anomalies to become available will persist.

The telescope structure currently doesn’t have any time blockers/limits, so we can skip this for now. For the satellite, I’m setting things as “one day prior” as a simple fix/work-around. Same with the rover. Additionally, we’ll need to adjust the timer between waypoints to be 60 seconds rather than 60 minutes? (or whatever the current value is). (I’ll set this to be if userClassifications < 4, because the user is doing multiple classifications for a single deployment of the rover…)
