### Determining 'plain alert' for new anomaly discovery
This update introduces more dynamic alert messaging for weekly gameplay milestones. We now check for recent planet discoveries in the `classifications` table — if a planet (`classificationtype = 'planet'`) has already been discovered in the last week, the "new planet" alert is skipped. Additionally, we’ve added new context-sensitive alert types based on structure-specific conditions: Weather Balloons may report sunspots, storms, or cloud anomalies; Telescopes may spot asteroids or new planets; and Greenhouses may detect sensor activity. The alert generator was updated to diversify feedback and improve player engagement with mission prompts.

```tsx
// Within milestone alert processing loop:

if (milestone.value === 'planet' && milestone.structure === 'Telescope') {
  // Check for recent planet classifications in the last 7 days
  const { data: planets, error } = await supabase
    .from('classifications')
    .select('*')
    .eq('classificationtype', 'planet')
    .gte('created_at', sevenDaysAgo.toISOString());

  if (planets.length > 0) continue; // Skip if already found
  msg = "New planet candidate discovered by your telescope.";
}

// Weather Balloon alerts
else if (milestone.structure === 'WeatherBalloon') {
  switch (milestone.value) {
    case 'sunspot':
      msg = "Sunspot activity detected — deploy Weather Balloon.";
      break;
    case 'satellite-planetFour':
      msg = "Dust storm activity reported — classify satellite visuals.";
      break;
    case 'automaton-aiForMars':
      msg = "Rover anomaly detected — help diagnose the issue.";
      break;
    case 'lidar-jovianVortexHunter':
      msg = "Cyclone patterns forming — analyze LIDAR imagery.";
      break;
    case 'cloud':
    case 'balloon-marsCloudShapes':
      msg = "Unusual cloud formations need your attention.";
      break;
  }
}

// Greenhouse sensor alert
else if (milestone.structure === 'Greenhouse') {
  msg = "Motion or sensor anomaly detected in desert/ocean pod — initiate analysis.";
}
```
