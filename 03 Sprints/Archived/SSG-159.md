## Weather events
#WeatherEvents 
Perhaps this would be the most logical thing to do next, now that we have terrariums with a biome generator (which helps identify the weather events that would be generated). So, we need to -
1. Simplify terrarium view, with backgrounds (test with AI generation for now until Fred has time to conduct the review)
2. Generate one weather event per day
3. Then, add other child anomalies into the #BiomeAggregator
4. Fix up the #JovianVortexHunter method

Weather events will take into account the following:
1. Weather events that the user has added to Earth, or that they've contributed to
2. Weather events (e.g. #CloudspottingOnMars ) that are on the terrarium
3. The biome & temperature of the terrarium

So maybe we implement the planet view described in [[Vegetation setup]], and simplify the size of the post card...
