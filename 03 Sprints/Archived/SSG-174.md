Changes between v33 & v45:
### Changes and Features Between Version 33 and Current Version


1. **Restored Visual Effects**: Brought back the full shader-based visual effects for planets, including:

1. Proper atmosphere rendering with transparency and color variations
2. Cloud layers with different patterns based on cloud types
3. Liquid surface rendering with reflections and depth effects
4. Visual distinction between terrestrial and gaseous planets


1. **Gaseous Planet Surface Points**: Added a toggle in the information panel to control whether surface points can be shown for gaseous planets
2. **Density Constraint for Oceanic Worlds**: Implemented a restriction preventing planets with density > 1.9 g/cm³ from being set to the "Oceanic World" biome

1. **Increased Maximum Planet Radius**: Expanded the maximum planet radius from 10 to 20 Earth radii to allow for larger gas giants
2. **Optional Parameters**: Made most parameters in the advanced generator optional, with only mass, radius, and temperature being required
3. **Default Values**: Added proper default values for all optional parameters to ensure the generator works with minimal input
4. **Improved Error Handling**: Fixed circular dependency issues in the `useMemo` hooks

1. **Better Landmark Management**: Enhanced the landmark system with selection and highlighting
2. **Improved Controls Organization**: Better organization of controls in the accordion panels
3. **Responsive Design**: Ensured the UI works well at different screen sizes
4. **Helpful Messages**: Added explanatory text for constraints (like the density limit for oceanic worlds)


1. **Precipitation Compounds**: Added support for different precipitation types (water, CO2, snow, methane)
2. **Enhanced Biome System**: Improved biome constraints and parameter ranges
3. **Topographic Map Integration**: Better integration between 3D view and topographic map
4. **Improved Cloud System**: Enhanced cloud rendering with support for multiple cloud types
