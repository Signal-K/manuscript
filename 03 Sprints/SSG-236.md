## Sharing posts

I think that this is a good concept, especially for when we get to scenes like `/planets/{id}`, however for now the main thing we need to show is the content that was being classified, the user's message and classification, and any options they've selected. Showing comments would also be a good step.

# Milestone updates
## Community milestones
Community milestones are a little harder to create a coherent structure/reason for, because until we get a consistent flow of users we can't really just have another format of "arbitrary number of classifications of arbitrary project". 

I think the reward for single player milestones should be bonus #Stardust, while community milestones will reward users with #Badges, which can be used to unlock bonus/exclusive content/components, or converted back into #Stardust 

For now, however, we'll just focus on badges. Maybe community milestones can be based around completing datasets or making a specific discovery that multiple people can participate in (e.g. consensus around confirming planets). This is a little harder to implement at the beginning, though, and I don't see this aiding user retention/addition yet.
