The field guide is a mechanic from Zooniverse that helps users identify certain anomalies/entities in an anomalous media file. In its simplest form, it shows an example of every landmark/image the users would be looking for in the project (e.g. an image showing all possible animals to discover in #Iguana project).

This page is going to serve as a list of all field guide examples from the various projects we include from #Zooniverse , as well as any additional scope or guides we add to non-Zooniverse projects.

We'll likely have a minimal control panel when you make the classification, that will allow parts of the FG to be shown, as well as the drawing tool (when we add that, also something likely to include in C3).

In C2, we'll include the field guide as essentially a button to ask for help (share the current anomaly) and show the tutorial again. We'll add proper functionality in C3. Field Guide should also include images next to classification options
