Here's a list of the "scientific output" or goal of each project:

- Planet Four: Mapping features on the Martian surface to understand sublimation patterns of CO2 ice. So users find deposits, these can be made into terrarium and resource sites and "mined".
    
- AI4M: Benchmark for terrain differences. Users can set paths for #RoversS to discover things, they'll present images from #APPEEARs and we'll eventually add in `AWS_JPL_OSR_DRL`
    
- CoM: Identifying how clouds form on Mars. Creates resources, which leads into the terrariums

* #PlanetHunter: Users can make their own planet. 

* #DailyMinorPlanet: Users can use asteroids for resource collection (mining scene addition) or later like in universe simulator(s) for population of content. e.g. Theia

*  #Disk-Detective: Users can make their solar system, which then leads into adding planets and other anomalies over time. Potentially can be useful for showing systems with multiple planet [candidates]
* Astronomer #upload : adding views, for use in terrariums? Maybe spotting things in terrariums can be part of the fun.

Weather - users will use weather to determine behaviour of things like the water cycle and soil composition. First thing is for users to make classifications, view them, rate them, and then we describe the next features. Users combine multiple anomalies into terrariums, which can then populate a planet. These terrariums will have mineral deposits generated, showing the cloud and topology. Soil analysis (of Earth) will occur when mining.

Planets - users create their own systems, spaceports, etc. Terrariums can be observed on Earth.

Bio - users determine traits and landscape behaviour, those traits then become available in certain terrariums (biosphere)

Bio - users can move anomalies into terrariums, which will have gravity, temperature and maybe some other traits. Those traits will determine population growth and eventually some limited behaviour.

So in short, these terrariums spawn things that are then rated. Maybe we update structures so they serve as "terrarium amalgamators?"

Uploads:

- Bio produces landscapes - traits mapping
    
- Meteo produces weather events
    
- Astro produces entities that can provide resources or other events
