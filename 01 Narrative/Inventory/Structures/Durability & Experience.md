## #SSM-66
I'm going to remove the requirement that a user's structure needs `configuration.durability` > 0.1 for users to post. I'm also going to remove the alteration to the structure's durability value (rather, comment it out). This is because there now isn't a tutorial for repairing structures, or even really a reason for structures to wear out (because you'd think the fetching data would be the hard part).

However, I'm not going to remove the functionality all together, because I want to reward users for making classifications, voting on others' classifications, and create a shared pool or community resource that gives our users something to work towards.
