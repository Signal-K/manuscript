### **Chapter 1: Basic Terrain Classification and Interaction**

**Missions:**

1. **Make one terrain classification:**
    
    - **What the user is doing:** Draw polygons around terrain types (sand, consolidated soil, bedrock, large rocks) on an image from the rover.
    - **How it relates to images:** Directly ties user input to identifying terrain types on a surface image.
    - **Utility:** Creates labeled data to train navigation systems for rovers on terrestrial planets.
2. **Comment on another user's classification (or your own):**
    
    - **What the user is doing:** Provide feedback or insights about polygons drawn by others.
    - **How it relates to images:** Engages users in collaborative analysis of terrain images.
    - **Utility:** Helps refine classifications and builds a shared understanding of terrain features.
3. **Vote on another user's classification:**
    
    - **What the user is doing:** Agree or disagree with another user's classification.
    - **How it relates to images:** Validates classifications, ensuring high-quality data.
    - **Utility:** Improves accuracy of terrain labels for training rover AI.
4. **Identify a sand-dominated region:**
    
    - **What the user is doing:** Locate and outline an area with primarily sand features.
    - **How it relates to images:** Users analyze patterns indicating sand-heavy terrain.
    - **Utility:** Highlights risky areas for rovers and potential sites for material collection.
5. **Find a consolidated soil patch:**
    
    - **What the user is doing:** Locate regions of packed, harder soil.
    - **How it relates to images:** Focuses on a terrain type important for stable rover movement.
    - **Utility:** Identifies areas that are safer for rovers to traverse or suitable for resource extraction.
6. **Mark regions with large rocks:**
    
    - **What the user is doing:** Identify and outline areas with prominent large rocks.
    - **How it relates to images:** Highlights obstacles to rover movement.
    - **Utility:** Avoidance of obstacles is critical for navigation and planning rover paths.

---

**End-of-Chapter 1 Visualizer:**

- **What the user is doing:** Users create a terrain map of a small section of the surface, showing identified terrain types (color-coded polygons).
- **Utility:** Provides a visual summary of classified regions and simulates how rovers "see" the terrain for navigation.

### **Chapter 2: Advanced Terrain Analysis and Context**

**Missions:**

1. **Assess terrain safety:**
    
    - **What the user is doing:** Rate a region's overall traversability based on terrain types (e.g., avoid sand, prioritize consolidated soil).
    - **How it relates to images:** Combines polygon data to determine the safest rover paths.
    - **Utility:** Directly simulates rover navigation decision-making for terrestrial exploration.
2. **Locate mixed-terrain regions:**
    
    - **What the user is doing:** Identify areas with a mix of sand, bedrock, and rocks.
    - **How it relates to images:** Analyzes complex terrain that might require nuanced navigation.
    - **Utility:** Helps refine navigation algorithms and informs terrarium designs with diverse surfaces.
3. **Highlight bedrock as a key feature:**
    
    - **What the user is doing:** Identify bedrock regions for stability and potential scientific interest.
    - **How it relates to images:** Users outline exposed bedrock patches that might indicate geological history.
    - **Utility:** Supports resource extraction, terrarium bases, or scientific analysis of planetary crusts.
4. **Connect terrain classifications to resource utility:**
    
    - **What the user is doing:** Predict what each terrain type (e.g., sand for glass production, bedrock for construction) might be used for.
    - **How it relates to images:** Translates terrain types into potential material applications.
    - **Utility:** Ties planetary exploration to mining operations and terrarium building.
5. **Hypothesize environmental conditions based on terrain:**
    
    - **What the user is doing:** Infer weather or environmental factors (e.g., wind patterns creating dunes, erosion exposing bedrock).
    - **How it relates to images:** Builds logical connections from surface features to planetary conditions.
    - **Utility:** Provides a narrative link between terrain features and planetary history for immersive gameplay.
6. **Classify terrain for mining suitability:**
    
    - **What the user is doing:** Tag regions based on mining potential (e.g., sand for raw materials, consolidated soil for stability).
    - **How it relates to images:** Applies classifications to practical in-game applications.
    - **Utility:** Enables resource harvesting and infrastructure planning.

---

**End-of-Chapter 2 Visualizer:**

- **What the user is doing:** Users expand their terrain map to include safety ratings, mining hotspots, and inferred environmental conditions.
- **Utility:** Provides an advanced terrain analysis tool for planning rover missions, mining operations, and terrarium layouts.
