## Chapter 2
### **Chapter 2 Missions: Dot Points**

---

#### **1. Correlate Cloud Types to Atmospheric Layers**

- **What the user is doing:**  
    Assigning classified clouds (e.g., bands, vortices, turbulent regions) to specific atmospheric layers (e.g., upper, middle, lower).
- **How it relates to classified images:**  
    Builds on user-identified cloud features by placing them into a structured vertical model of the atmosphere.
- **Utility:**  
    Helps understand atmospheric dynamics and supports terrarium creation with realistic weather systems.

---

#### **2. Link Clouds to Chemical Compositions**

- **What the user is doing:**  
    Matching cloud classifications to potential chemical signatures (e.g., ammonia clouds, methane-rich regions).
- **How it relates to classified images:**  
    Uses visible features like color or structure (e.g., brown barges or red cyclones) to infer chemical makeup.
- **Utility:**  
    Connects classifications to resource mapping (e.g., ammonia for mining) and builds chemical profiles for gaseous planet terrariums.

---

#### **3. Unlock Ammonia Storm Regions**

- **What the user is doing:**  
    Identifying storm-prone regions based on vortex and turbulence classifications to "unlock" ammonia-rich areas.
- **How it relates to classified images:**  
    Users focus on turbulent or vortex-heavy regions that imply active storm dynamics.
- **Utility:**  
    Highlights ammonia as a valuable resource for other projects (e.g., fuel or terrarium building).

---

#### **4. Classify Clouds Within Storm Regions**

- **What the user is doing:**  
    Further subdividing storm systems into specific cloud types (e.g., turbulent edges, calm cores, high-velocity regions).
- **How it relates to classified images:**  
    Builds detail into storm regions users have already classified, adding granularity.
- **Utility:**  
    Enhances storm simulations for visualizations and informs resource distribution within dynamic systems.

---

#### **5. Hypothesize Atmospheric Processes**

- **What the user is doing:**  
    Predicting how classified clouds interact with underlying dynamics, like wind patterns or vertical mixing.
- **How it relates to classified images:**  
    Builds on classified cloud regions to simulate broader atmospheric flows or processes.
- **Utility:**  
    Adds realism to cloud-based terrariums or resource modeling, tying into broader planetary exploration.

---

#### **6. Visualize Cloud-Based Atmospheric Layers**

- **What the user is doing:**  
    Generating a layered atmospheric model based on their classifications (e.g., ammonia clouds in the upper layer, water deeper down).
- **How it relates to classified images:**  
    Combines multiple classifications into a single cohesive visualization.
- **Utility:**  
    Progresses the generator/visualizer mechanic and sets up Chapter 3 for mining and astrobiology investigations.

---

#### **7. Map a Cloud to a Region on a Gaseous Planet Candidate**

- **What the user is doing:**  
    Linking classified cloud regions to gaseous planet candidates identified in the **Planet Hunters** project.
- **How it relates to classified images:**  
    Users reference the original cloud types to populate sections of a gaseous planet’s atmospheric map.
- **Utility:**  
    Bridges projects (e.g., **Jovian Vortex Hunters** and **Planet Hunters**) and creates a shared knowledge base of planetary atmospheres.

---

#### **End-of-Chapter Visualizer: Atmospheric Map**

- **What the user is doing:**  
    Users expand on their Chapter 1 visualizations by creating an atmospheric map with layers (e.g., ammonia clouds, methane-rich bands).
- **Utility:**  
    Combines user classifications into a dynamic planetary atmosphere visualization, showing chemical distributions and cloud systems.

---

These missions focus on tying user classifications to chemical compositions, atmospheric structure, and broader planetary modeling while progressing the generator/visualizer mechanic.

## Chapter 3
### **Chapter 3 Missions: Dot Points**

---

#### **1. Hypothesize Astrobiological Potential**

- **What the user is doing:**  
    Identifying cloud regions with chemical compositions (e.g., methane, ammonia) that might support prebiotic or biological activity.
- **How it relates to classified images:**  
    Users reference classified cloud bands or turbulent regions with specific chemical signatures.
- **Utility:**  
    Highlights gaseous planets as potential "organic material factories" contributing to planetary ecosystems. May inform life-building elements in terrariums or link to **Planet Hunters** for terrestrial planets with these organics.

---

#### **2. Mine for Resources in Storm Regions**

- **What the user is doing:**  
    Selecting storm or vortex regions for resource extraction based on prior classifications.
- **How it relates to classified images:**  
    Storms and vortices tied to high chemical activity (e.g., ammonia, hydrogen, methane) guide mining opportunities.
- **Utility:**  
    Provides resources for terrariums, fueling exploration or other game components. Highlights chemical diversity of gas giants for resource extraction.

---

#### **3. Search for Organic Signatures**

- **What the user is doing:**  
    Identifying regions (e.g., methane-rich cloud bands) with potential for organic molecule formation.
- **How it relates to classified images:**  
    Builds on user-selected compositions in cloud bands or turbulent regions to locate areas likely to harbor prebiotic chemistry.
- **Utility:**  
    Explores gas giants as sources of organic material for terrestrial planets or terrariums, emphasizing their role as "melting pots."

---

#### **4. Map Atmospheric Habitats for Hypothetical Life**

- **What the user is doing:**  
    Combining classified features into theoretical "habitats" for microbial life based on chemical and dynamic conditions.
- **How it relates to classified images:**  
    Users use cloud bands, turbulent areas, or vortices to simulate regions with varying levels of habitability.
- **Utility:**  
    Sets groundwork for terrarium ecosystems, speculating how life could adapt to gaseous environments. May tie into terrestrial planet projects via organic material migration.

---

#### **5. Visualize Resource Distributions on Gaseous Planets**

- **What the user is doing:**  
    Creating a resource map based on classified regions (e.g., methane-rich clouds, ammonia storms).
- **How it relates to classified images:**  
    Users’ classifications feed into a heatmap showing resource intensity across the planet.
- **Utility:**  
    Guides resource usage for terrariums or interlinked missions (e.g., using mined resources to terraform terrestrial planets in **Planet Hunters**).

---

#### **6. Identify Unique Atmospheric Phenomena**

- **What the user is doing:**  
    Flagging rare or unique features (e.g., giant cyclones, unusual colors) for study.
- **How it relates to classified images:**  
    Users identify anomalies from prior classifications or by revisiting certain regions.
- **Utility:**  
    Could reveal high-value resource areas or regions with exceptional astrobiological or terrarium-building potential.

---

These missions balance mining, astrobiology, and creative ecosystem building while leveraging the classified source images.
